# F14 — izbor jezika aplikacije

Kriterijumi: sistemski jezik, English i Srpski (latinica) mogu se izabrati u podešavanjima od API 26 naviše. Izbor preživljava ponovno kreiranje i ponovno pokretanje aplikacije; na API 33+ usklađen je sa Android Settings. Promena ne prevodi već upisani tekst, ne zatvara tablu i ne gubi nesnimljene izmene. Dugi tekst/font scale mora ostati dostupan u skrolabilnom dijalogu, uz jednu radio kontrolu i najmanje 48 dp po izboru.

Implementacija prati [Android uputstvo za jezike aplikacije](https://developer.android.com/guide/topics/resources/app-languages): AppCompatActivity, AppCompatDelegate.setApplicationLocales i autoStoreLocales metadata na isključenom, neizvezenom AppLocalesMetadataHolderService-u. Na API 33+ Android čuva jezik; stariji sistemi koriste AppCompat privatno skladište. Ne uvoditi drugi DataStore jezički ključ ili menjati globalni Locale.setDefault. Podržani locales_config već sadrži en i sr-Latn. Dodata je stabilna [AppCompat 1.8.0](https://developer.android.com/jetpack/androidx/releases/appcompat) verzija od 12. avgusta 2026, uz odgovarajuću Light.NoActionBar temu; Compose i dalje određuje korisničku svetlu/tamnu temu.

Presentation dobija semantički AppLanguage izbor bez Android zavisnosti u domenu. Nepodržan spolja postavljen locale ne prikazuje se kao lažno izabran sistemski/engleski jezik. Promena ide kroz composition root na glavnoj niti; postojeći ViewModel-i i rememberSaveable stanje opstaju pri konfiguracionom restartu, a recovery flush ostaje aktivan. F15 dobija novi resource jezik tek pri pravljenju sledeće table.

Status: kvalifikovano u 0.6.4/source 9589e12/CI 41874486383, svih šest poslova uspešno. 283 JVM i pet profila po 97 app + 13 data prolaze; uključeni su izbor/recreation/nesnimljeni dokument i radio accessibility. Na API 26 telefonu/tabletu i API 36 R8 paket prolazi oba jezička process-restart slučaja, Save/reopen i vraćanje prvobitnog jezika. Licence/notices/OSV inventar ima 155 komponenti. Paket i hash-evi: LOCAL-0.6.4-CANDIDATE.md. Ovo ne zatvara H dokaz stvarne in-place OS nadogradnje ili fizičkog uređaja.

AppCompat podrazumevano uključuje EmojiCompat podršku. U skladu sa [zvaničnom mogućnošću isključivanja initializer-a](https://developer.android.com/develop/ui/views/text-and-emoji/emoji2), aplikacija uklanja samo EmojiCompatInitializer metadata, uz očuvan Startup provider i druge postojeće inicijalizatore. Koriste se sistemski fontovi/emoji, bez novog automatskog zahteva font provider-u; APK security gate odbija povratak tog initializer-a. Nema nove mrežne dozvole ili online modula.
